# 決定

> 第3章のうち、上部バーをスクロールで詰める（1）と、メニューの中身（2）を、この決定で置き換えた。第1章（ログイン）と第2章（復旧ドラフト）は変えない（[ADR-0011](0011-passkey-first-and-compact-ui.md)）。

## 1. 上部バーは最初からコンパクトにし、大きさを変えない

1. 上部バーには、アプリ名・いまの画面の名前（フォルダを開いたとき）・開いている場所の名前・メニューを1行に置く。説明文（「手元のMarkdownで記事をつくる、ローカルCMS。」）は外す。説明文は README に残る。
2. 画面の上に固定し（`position: sticky`）、どの画面でも同じ高さにする。スクロールで縮めない。
3. 高さが変わらないので、ページの高さもスクロールの位置も変わらない。ADR-0011 は縮めた分を上部バーの下の余白で埋めて高さを保っていたが、説明文のある最初の画面では高さの差が大きく、詰める・戻すの動きが目立った（2026-11-09）。縮める処理と余白の補正をなくし、この問題の原因を取り除く。
4. メニューの開閉はアイコン（≡）だけにする。名前「メニュー」は読み上げ（`aria-label`）とツールチップ（`title`）で伝える。

## 2. メニューに画面とツールを集める

1. メニューには、次の項目を置く。
   - 画面（記事・Git と同期・設定。狭い画面は「一覧」「編集」を分ける）：フォルダを開いた後。
   - 場所（作業場所の一覧に戻る、または別のフォルダを開く）：作業場所を開いているとき、またはフォルダを開いているとき。
   - 復旧ドラフト（件数つき）：ログインした後、復旧ドラフトを使えるとき。
   - 対応環境の確認：いつでも。
   - ヘルプ：いつでも。
   - ロック：ログインした後。
2. ログインの画面でも、同じ上部バーとメニューを出す。ログインの前に出すのは「対応環境の確認」と「ヘルプ」だけ。復旧ドラフトとロックは、ログインした後にだけ出す。
3. 復旧ドラフトの一覧と「対応環境の確認」は、画面の本文から外し、メニューから開くダイアログにする。ヘルプは元からダイアログだった。ダイアログを閉じると、開閉のボタン（≡）へフォーカスを戻す。
4. 開閉のボタンの右上の点は注意を示す。警告（この環境では使えない）は危険の色、情報（未確認の復旧ドラフトがある）はアクセントの色。点と同じことを、ボタンの説明（`aria-describedby`）でも伝える。

## 3. 対応環境の確認

1. すべて使えるときは、要約（「このブラウザで使えます」）だけを見せ、項目の一覧は畳む。
2. 使えないときは、メニューの項目に「この環境では使えません」を出して警告の印をつける。ダイアログの要約は警告の色にし、項目の一覧は開いた状態で出す。
3. 「この環境では不要」の行で列がずれていた。項目の一覧を1つのグリッドにし（subgrid）、行の列を揃えた。

## 4. 作業場所の操作

1. 行の「書き出す」「削除」は、「…」を開いたときに出す。「…」は Esc で閉じると「…」のボタンへ戻り、外側を押したときは閉じるだけ。
2. 作業場所が1つもないときは、「新しい作業場所」と「取り込む」をそのまま出す。作業場所があるときは、「新しい作業場所・取り込み…」の折り畳みに入れる。タブにはしない（操作の数に対して部品が増え、画面の切り替えと見分けにくくなる）。

## 5. 保存領域を消さないよう求める

1. 押すと、ボタンは「確認しています…」になって押せなくなり、結果を1行で出す。結果は、許可された・許可されなかった・この環境では求められない、の3つ。
2. 結果の欄は、求める前から置く（`role="status"`）。結果がないときは何も出さない。

# 理由

- 説明文のある上部バーと縮む上部バーは、サイズが変わるたびに画面が動いて見えて目障りだった（依頼）。最初から小さく固定すれば、動きの原因そのものがなくなる。
- ログインの前と後で、上部バーとメニューの位置・中身を同じにする。画面ごとに違うと、ログインの後にどこで何を押すのか分からなくなる。
- 書き出し・削除のような取り返しにくい操作は、行の「…」の中に置き、画面の切り替えと並べない。
- 復旧ドラフトと対応環境の確認は、本文の作業を圧迫せず、必要なときだけ開けばよい。

# 未決・残る課題

- 「ロック」の名前。ログインと対応させて「ロック解除」とする案がある。この変更では名前を変えていない。名前は 0x0da160 の判断を待つ。
- 実機（iPhone・iPad の Safari、VoiceOver）でのメニューとダイアログの操作と読み上げは未確認。確認はヘッドレス Chromium の 390・900・1280 幅だけ。
- 「…」の中の「書き出す」「削除」が見つかるか（発見性）。
