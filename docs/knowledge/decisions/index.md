# 設計判断

* [ADR-0001 技術スタックの選定](0001-tech-stack.md) - 単一HTML・file://起動・外部CDN非依存の制約下で、Vite 8 + Svelte 5 + TypeScript と vite-plugin-singlefile を採用する決定と、仕様との要検証点。
* [ADR-0002 P1 MVP：読み込み・編集・手動保存の実装方式](0002-p1-editing-and-save.md) - フォルダ選択・記事一覧・作成と編集・手動保存・ID と slug・YAML 往復保持の実装方式と、未検証の技術ゲート、仕様との緊張点。
* [ADR-0003 P1 MVP：プレビュー・画像・複製・削除・復旧ドラフトの実装方式](0003-p1-preview-media-drafts.md) - Markdown プレビュー、画像の取り込みと削除、記事の複製と削除（リポジトリ外への検証済み退避）、ブラウザ内復旧ドラフトの実装方式と、未検証の技術ゲート、仕様との緊張点。
* [ADR-0004 P1 MVP：ローカル Git 機能と残りの項目の実装方式](0004-p1-git-and-remaining.md) - 記事単位のステージとコミット・git init・状態と履歴の表示を、外部プロセスを使わない自前の Git 実装で行う方式と、ID・createdAt の専用修正、コードハイライト、配布物の真正性情報。未検証の技術ゲートと仕様との緊張点。
* [ADR-0005 見たまま編集・画像の最適化と派生画像・前回のフォルダの記憶](0005-wysiwyg-images-recent-folder.md) - 依頼により仕様 3.1 の対象外（リッチテキスト編集・原本の最適化・フォルダの永続化）を取り入れる決定。本文の見たまま編集を Markdown を正本としたまま実装する方式、取り込み時の画像の上限と派生画像、前回のフォルダの記憶。未検証の点と仕様との差。
* [ADR-0006（案）iOS Safari で記事と Git を扱うための計画](0006-ios-safari-git-plan.md) - iOS Safari で記事の編集とローカル Git を使うための計画。File System Access API への依存、ブラウザ内ストレージ（OPFS または LightningFS）への置き換え、取り込みと書き出し、消去の危険、仕様の変更箇所、Git 層の選択、暗号化とパスキー、GitHub の REST API による push・pull、規模と未決事項。一部決定。
* [ADR-0007 デザインシステムの再構築と Oklab のカラーパレット](0007-design-system-oklab.md) - デザイントークンを TypeScript の正本から CSS に生成して一か所で定義し、カラーパレットを Oklab の明度の等間隔な段で作る決定。生成方式、意味の色の割り当て、WCAG 2.1 AA の自動検査、旧い変数名からの移行の段取り。
* [ADR-0008（案）ホスト版で GitHub にログインして同期するための計画](0008-hosted-github-login-plan.md) - PAT を作らずに GitHub へのログインだけで同期する計画。トークン取得の窓口が CORS に対応しない問題を、ホスト版を Cloudflare Pages に移して同じ配信元の小さな関数で解く。デバイスフロー、関数の範囲、GitHub App の設定、配信元の変更でブラウザ内のデータが引き継がれない危険と移行手順、仕様の変更箇所、段階と未決事項。file:// 版は PAT のまま。未着手。
* [ADR-0009 記事の任意の標準項目（説明文・旧 slug・読者向けの更新日時・訂正・著者・カバーのキャプションとクレジット）](0009-optional-article-fields.md) - 他の CMS との比較調査の P1 の 5 件を、frontmatter の任意の標準項目として実装する決定。項目の形と検証、ない項目をフォームで足す方式、公開後の slug 変更で旧 slug を残す流れと重複検査、content/authors/ からの著者の読み込み、複製時の扱い、未対応の点。
* [ADR-0010 デザインシステム 0.4.0 の導入（ブランド色・面の段・状態色・操作状態）](0010-design-system-0-4.md) - 敵対的レビューで完成させたデザインシステム 0.4.0 をアプリに導入する決定。正本は palette.ts・tokens.ts のまま、ブランド6色と OKLCH の段、面の段、64 の意味の色、注意（warning）の追加、影と暗幕のテーマ別化、操作状態、検査対象 178 組。旧い --color-* からの対応表と見た目の変化。
* [ADR-0011 起動時のパスキーでのログイン・暗号化した復旧ドラフト・詰めた画面](0011-passkey-first-and-compact-ui.md) - 起動したら先にパスキーを登録・認証し、ログイン鍵で復旧ドラフトを暗号化して既定で有効にし、暗号化した作業場所もログインだけで開けるようにする決定。上部バーの固定とスクロールでの縮小・メニュー化、押せる高さの規則（WCAG 2.5.8・Apple HIG）、表の罫線、見たまま編集のカーソルの近くの書式の帯。
* [ADR-0012 パスキーだけのログインと、ログインの鍵でのアプリ全体の暗号化](0012-passkey-only-login-whole-app-encryption.md) - ログインをパスキーだけにしてパスフレーズをなくし、ブラウザ内の作業場所を常にログインの鍵で暗号化する決定。作業場所ごとの暗号化の選択・回復コード・パスキーをなくし、file:// では使えず https の配信元か localhost から開く。書き出しはログインの回復コードで開ける版 2 の形式。
* [ADR-0013 上部バーの大きさを変えず、画面とツールをメニューにまとめる](0013-header-menu-consolidation.md) - 上部バーから説明文を外して最初からコンパクトにし、大きさを変えない決定（ADR-0011 のスクロールでの縮小を取りやめる）。復旧ドラフトと対応環境の確認をメニューから開くダイアログにし、非対応の環境では警告を出す。ログインの画面でも同じメニューを出す。作業場所の「書き出す」「削除」は「…」に入れ、「新しい作業場所」と「取り込む」は折り畳む。保存領域の求めには結果を示す。ロックの名前は ADR-0014 で決めた。
* [ADR-0014 以前の版との互換をなくし、表現を「ロック」と「ロック解除」の対にする](0014-lock-unlock-wording-and-no-backward-compat.md) - 以前の版との互換（パスフレーズ・作業場所ごとの回復コードとパスキー・移行処理・以前の形式の書き出し）をなくしてコードを削除し、起動時の認証を「ログイン」と呼ばず「ロック」と「ロック解除」の対で表す決定。コード上の名前（login）と保存する形式は変えない。
* [ADR-0015 iPhone 17 の Safari を主な対象にして画面を整える（デザインシステム 0.5.0）](0015-iphone-17-safari-first-ui.md) - 画面を iPhone 17 の Safari（402×874）を主な対象にして整える決定。指の画面の押せる大きさをすべて 44px にし（ADR-0011 の段を置き換える）、安全領域と画面キーボードに追従させ、編集画面を「本文」「記事情報」のタブと画面の下の操作バーに分け、書式の帯を画面の下に付け、ダイアログを下からのシートにする。hover の規則、画面の言葉の統一、実機で確かめていない点。
