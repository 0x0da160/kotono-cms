## 36. 操作確定点・中断・再試行表（P1）

| 操作 | 完了条件・確定点 | 取消可能な境界 | 中断後・再試行条件 |
| --- | --- | --- | --- |
| 保存 | 第13.2.2節の最終候補検証後、候補とディスクの再読込一致。保存リビジョンを基準化 | 書込開始前。書込中はAPIのabort挙動を検証し、保証できる範囲のみ | 基準／候補／第三版／読取不能を判定。後続編集は保持 |
| 新規作成 | 最後の正常index.mdが再読込一致 | 未確定のファイル工程間 | 不完全パスを表示。所有不明の先へ自動再利用しない |
| 複製 | 元再照合と全コピー検証後、最後のindex.md一致 | ファイル工程間 | 完成と不完全を再走査。元変更なら新たな確認 |
| 画像取込 | 1ファイルの形式検証・書込・再読込一致 | 次ファイル前。安全と実証済みの単一ファイル内境界 | 成功分保持。残存・未挿入・失敗を個別表示 |
| 削除前退避 | 退避マニフェスト・内容の再読込一致と元再照合 | ファイル工程間 | 退避完成を照合できるまで削除禁止 |
| 記事削除 | 第11.3節の対象編集停止を維持し、全確認対象の消失確認 | 個別削除間。ただし削除済みは戻らない | 残存・不明を再列挙し、追加操作は再確認。対象記事はコピー・退避を可能にする |
| 画像削除 | 第11.3節のリビジョン照合・個別削除中の対象編集停止、全確認対象の消失確認 | 個別削除間。確認後の編集で残りを停止 | 保存または破棄後に新たに確認。削除済み・残存・不明と退避先を表示 |
| コミット | 既知コミット・HEAD・親・対象ツリー・indexを照合 | ステージ前。ステージ後は無断解除せず、確定工程の取消可否を明示 | 同一セッションかつ予定一致のみ再試行。由来不明は外部Git |
| 作者設定保存 | 対象設定の再読込一致と他設定保持 | 書込前 | コミット結果とは別に判定。設定失敗をコミット失敗へ混同しない |
| ドラフト退避 | 該当リビジョンの永続保存・整合性検証 | 保存要求間 | 最新成功版を維持。失敗をUIへ通知 |

- 新規作成のcreatedAtは編集開始時刻を保持し、初回保存の再試行やドラフト復旧でも取り直さない。新規作成のupdatedAtは初回保存の最終候補生成時刻とする。複製のcreatedAt／updatedAtは最終index候補確定工程で取得した同一の時刻とする。実際の工程終了時刻との厳密一致は意味しない。再試行で新候補が必要な場合のみ、新規作成のupdatedAtまたは複製の両日時を再取得する。
- 再確認が必要な変更を検出した場合、旧確認ダイアログを流用しない。
- 操作ログはUI上の判断材料であり、永続トランザクションログの代替ではない。再起動後は実状態から判断する。
