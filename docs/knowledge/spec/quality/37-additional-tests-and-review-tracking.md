## 37. 追加受け入れ試験・レビュー追跡（P0／P1）

### 37.1 故障・攻撃シナリオ

各試験に環境、前提、注入位置、期待するUI・ファイル・Git状態、前後の内容ハッシュ、実結果、残存物、回復手順を記録する。試験ハーネスの注入と実ブラウザ強制終了を併用する。画面表示だけで合否を決めない。

| ID | 内容 | 合格条件 |
| --- | --- | --- |
| T01 | 存在確認直後・ハンドル取得直後に同名ファイル／フォルダを外部作成 | 外部内容を黙って上書きしない。実証不能部分はゲート未合格／再合意 |
| T02 | Gitメタデータの各I/O境界でタブ・ブラウザ強制終了 | 破損・不明の検出、外部Git検証、成功の誤表示・重複コミットなし |
| T03 | 複製の任意ファイル後・index確定前後で終了 | 完成前の正常記事誤認なし。完成後も実状態照合 |
| T04 | mediaへ外部配置した偽装・巨大・異常・差替え画像 | 取り込みUIなしでも表示検証・固定上限が効く |
| T05 | 深いYAML、大量ノード、巨大表、長大行、重いハイライト・差分 | 予算内で拒否／中断し、UI・原文退避を維持 |
| T06 | 深い階層・大量小ファイル・容量超過の複製／削除／退避 | 列挙完了前の破壊操作なし、進捗・取消・上限説明 |
| T07 | 描画層へ想定外要素・属性・URLを注入 | 親DOM・ハンドル・Git権限へ到達不可、自動通信なし |
| T08 | Git設定include、alternates、commondir、不正ref・indexパス | 領域外参照なし、安全な停止、記事編集への影響限定 |
| T09 | 2時間運用・記事切替・画像・Undo反復 | 応答目標、メモリ増加基準、資源解放を満たす |
| T10 | IME中の保存、モード切替、Undo、権限失効を組合せ | 欠落・二重入力・古い版への巻戻りなし |
| T11 | 確認後・実行直前・実行中の対象差替え | 検出範囲で停止、未確認対象削除なし、非保証を過大表示しない |
| T12 | 保存中に入力・Undo・フォーム変更 | 保存済み基準と後続編集を分離、未保存表示が正しい |
| T13 | ドラフト有効化拒否、容量不足、破損、期限、ブラウザ再起動。退避中の破棄・削除・保存・無効化後に古い要求を遅延完了させる | 第33.3.1節の順序が永続状態にも成立。破棄済み復活・新旧巻戻り・無効化完了後の新規永続保存なし。保存後の編集世代は保持 |
| T14 | HTMLの移動・改名・更新、別プロファイル、ストレージ消去 | 復旧可能範囲と失敗理由の表示、更新前退避案内 |
| T15 | 削除前退避の容量不足・権限失効・検証不一致 | 削除開始なし。元を保持し残存退避先を表示 |
| T16 | 削除途中失敗後、退避から外部復元 | 残存識別、無確認再削除なし、復元後整合性検証 |
| T17 | 既存indexの特殊フラグ・intent-to-add・外部ステージ | 混入・自動解除なし、判定不能時はGit書込停止 |
| T18 | 10,000コミット、対象変更がまばらな記事履歴 | 表示50件と内部予算を分離、継続・取消、未調査表示 |
| T19 | 配布物改変、依存差替え、未検証ブラウザ、既知障害版 | 正式版の確認手順、版表示、重大障害時の該当操作停止 |
| T20 | キーボード、支援技術、200%ズーム、単一ペイン | 主要作業完了、フォーカスと状態通知が正しい |
| T21 | キー順・大整数・指数・特殊数値・日時オフセット・コメント帰属 | 第8・9章どおりの保持とupdatedAt判定 |
| T22 | 非対応構文内の参照、独自フィールド、別記事参照 | 保護範囲を表示、判定不能を未使用と誤認しない |
| T23 | 改ざんマニフェスト・ドラフト・診断ログの再読込 | HTML解釈・逸脱・無制限処理なし |
| T24 | 退避先が元と同一・配下・危険な重なり・間接参照 | コピー・削除開始前に拒否または安全性を実証 |
| T25 | 新規作成後に時間を置いて初回保存、失敗再試行、未保存新規ドラフト復旧、複製と再試行 | 新規createdAtは開始時刻を維持。updatedAtと複製両日時は第8・36章どおり。候補確認済み時は不要な再生成なし |
| T26 | 巨大設定、巨大index・packed-refs、大量ref・記事エントリー、巨大マニフェスト・ログ・ドラフト付随データ | 第34.5節の全入口で読込前・構築中に停止。UI・退避維持、影響範囲限定。未調査を完全結果としない |
| T27 | 日本語・絵文字、貼付け・フォーム変更、YAML直列化・日時反映後の最終UTF-8サイズと構造の境界、プレビューのみの超過 | 書込前に最終候補の読込編集条件を検証。超過時は既存不変・編集救出可。正常保存後に同版で再編集可。プレビューだけの超過では保存を妨げない |
| T28 | 記事削除確認中の編集・Undo・挿入、画像退避中の参照追加、削除直前とAPI待機中の編集試行、複数削除間の変更 | 第11.3節どおりの対象限定制御。旧確認の流用なし、新たな参照を無視しない。部分削除時の残存・退避を表示。別記事・UIへ不要な停止なし |

- T25〜T28はMVP必須試験とする。T11・T12・T13・T23等との同じ実行記録を共有できるが、全注入順序と期待状態を対応付ける。
- T13の遅延完了試験は、古い要求と新しい要求の完了順反転、各整理操作の前後での強制終了、再起動後の実ストレージ照合を含む。メモリ上のUIだけで合格としない。

| 画像メモリ・アニメーション | デコード・保持予算と静止プレビュー | 17、34.3 |
| 履歴50件と内部処理量の混同 | 内部予算・継続カーソル・未調査表示 | 22、T18 |
| 文書・Undo・DOM増幅 | 共通正本、履歴予算、仮想化、長時間測定 | 14、23、34、T09 |

| IME・アクセシビリティ | 主要フローの必須受け入れ | 14.1、T20 |
| 公開状態の誤認 | 公開対象・保存・Git・配信未確認を分離 | 7.3、23 |
| YAML・日時等の解釈差 | 文法・同値・コメント帰属を固定 | 8、9、T21 |
| Gitステージ・外部ポリシー | 特殊index検出と観測不能条件の明示 | 20、21、T17 |
| 保証・権限・資源・確定点の欠落 | 現行要件として付表を必須化 | 16.1.1、34〜36 |
| 新規createdAtと確定点表の矛盾 | 新規は開始時刻を維持、複製は最終候補工程の同一時刻 | 8、10、36、T25 |
| 未信頼入力の予算対象漏れ | 非objectメタデータ・設定・列挙・再読込形式も入口別に有界化、数値確定をリリース条件化 | 4、20、34.5、T26 |
| 保存後に自CMSで再編集不能となる候補 | 最終UTF-8候補で読込編集条件を検証。プレビューだけの制限は分離 | 13.2.2、34、T27 |
| 削除中の後続編集と新規参照 | 対象記事の編集停止・リビジョン変化時の確認失効・個別削除確定工程 | 11.3、18、19、36、T28 |
| ドラフトの遅延完了による復活・巻戻り | 永続状態でも世代・整理操作の順序を保持し、実ストレージで検証 | 33.3.1、T13 |

### 37.3 リリース判定用成果物

1. 対応環境・ブラウザ更新方針表。
2. fsアダプター意味論表とGit I/Oトレース。
3. Git互換性表、外部ポリシーの非保証説明。
4. 保証境界表と未成立項目ゼロの確認。
5. 権限境界図、CSP・メッセージ・許可要素・URL・パス規則。
6. 資源予算表、性能付表、長時間運用測定結果。第34.5節の入口別予算の数値承認・実装対応表・超過時の限定停止を含む。
7. 操作確定点表、中断・再試行・退避・手動復元手順。最終保存候補の再読込条件、日時、削除中の対象編集制御を含む。
8. YAML保持・意味的同値・日時・コメントのフィクスチャ。
9. 復旧ドラフトの形式・プライバシー・期限・失敗・更新時の説明、非同期要求と破棄・保存・無効化の順序保証・中断試験記録。
10. A／D／F／G／S／PおよびT01〜T28の試験記録。
11. 正式配布元、成果物検証情報、依存一覧、ライセンス、セキュリティ告知先。
12. 未検証事項と既知の制限の区別、アプリ版・仕様版の対応。

未検証や未成立を「注意して使う」の一文で完了扱いしない。MVPの成立条件が満たせない場合は、要件・方式・対象範囲の再合意を先に行う。
