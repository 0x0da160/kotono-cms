# プロダクト

* [Kotono CMS の名称と表記ルール](naming.md) - プロダクト名「Kotono CMS」と英字識別子 kotono-cms の用途別名称・表記ルール・留意事項。
* [Kotono CMS のデザインシステム](design-system.md) - デザインシステム 0.5.0。デザイントークン（色・文字・余白・角丸・影・フォーカスの輪・重なり順・動き・画面の端とキーボード）の正本の場所、ブランド6色と OKLCH のパレット、面の段、意味の色と状態色、操作状態、指の画面の規則（44px・安全領域・画面キーボード・下の操作バー・シート）、コントラストの基準、CSS を書くときの規則。
* [Kotono CMS のアプリの外枠（シェル）](app-shell.md) - アプリ全体の領域（上部バー・お知らせの帯・画面・フッター）、上部バーでの画面の切り替え（記事／Git と同期／設定）、狭い画面（iPhone 17 の Safari が主な対象）での並びと編集画面のタブ・下の操作バー、各機能の置き場所と決定の理由。
